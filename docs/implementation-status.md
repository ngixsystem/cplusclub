# Состояние реализации — 2026-09-29

## Карточки оборудования и USD — 2026-10-08

- Реестр оборудования представлен адаптивными карточками с SVG-иконками ПК, серверов и сетевых устройств. Поиск и пагинация сохранены.

## Выбор ПК в заявке — 2026-10-07

- При создании заявки доступен список ПК выбранного клуба; смена клуба сбрасывает выбранное устройство.
- Заявка хранит постоянную связь с ПК и содержит ссылку на его карточку. Общие заявки могут оставаться без привязки.
- История неисправностей в оборудовании показывает открытые и закрытые заявки с постраничным просмотром вместо ограничения первыми 50.
- Backend: 43 теста / 494 assertions; TypeScript и сборка прошли. Подробности: [ticket-equipment.md](ticket-equipment.md).

## Отчёты о закрытых заявках — 2026-10-07

- По умолчанию отчёты показывают закрытые заявки, включая заявки без трудозатрат. Старый учёт затрат сохранён отдельной вкладкой.
- Фильтры: клуб, оборудование, назначенный исполнитель и период в Asia/Tashkent. CSV использует те же фильтры и выгружает все страницы.
- В отчёте есть причина, решение, выполненные работы, проверка, дата закрытия и расходы отдельно по валютам.
- Backend: 40 тестов / 429 assertions; TypeScript и сборка прошли. Семантика дат и сумм: [reports.md](reports.md).
- Следующие задачи: уведомления о ходе заявки, резервное копирование с проверкой восстановления и пилотная приёмка.

## Согласование заявок — 2026-10-07

- Предложения работ: описание, сумма, валюта, срок, автор и история решений. Изменённые условия требуют нового согласования.
- Представитель своего клуба может согласовать/отклонить предложение и принять результат/вернуть на доработку; общего права редактировать заявку он не получает.
- Старые заявки сохранены. Прежнее закрытие сотрудником доступно только заявкам без предложений; согласованные работы закрывает представитель клуба.
- Добавлены защита версий, блокировка обхода согласования через старый API и тесты ролей, повторных решений и отказов.
- Проверки: 37 backend-тестов / 335 assertions; 5 браузерных сценариев; TypeScript и сборка. Подробности: [ticket-approval.md](ticket-approval.md).
- Следующий этап: отчёт по закрытым заявкам и фильтры. Уведомления о согласовании ещё не подключены.

## Обновление 2026-09-30: iCafeCloud

- Реализован и опубликован дашборд клуба: открытые кассовые смены, график поступлений, недельная таблица с детализацией и онлайн/офлайн ПК.

- Браузер обновляется без перезагрузки каждые 15 секунд; backend ограничивает обращения к API кешем 30 секунд и сохраняет последние данные при сбое.
- Подтверждено в изолированном Docker-окружении VPS: 21 backend-тест / 119 assertions, 2 Playwright-сценария, TypeScript и production-сборка.
- Проверены реальные данные API и production-подключение. Подробности, ограничения отчётов и развёртывание: docs/icafe-dashboard.md.

## Реализовано в исходниках

- Laravel 13 / PHP 8.4, Vue / TypeScript / Inertia, PostgreSQL, Redis / Horizon.
- Клубы, оборудование, пользователи и членство, политики доступа, заявки и история переходов.
- Приватные вложения, QR, трудозатраты и отчёты, осмотры и выезды.
- API телеметрии, Windows-агент и симулятор, правила тревог и обслуживание данных.
- Проверки опубликованных и локальных версий игр; отдельные подтверждения специалиста.
- Telegram transport, outbox, журнал попыток и повторная доставка; реальные интеграции не подтверждены.
- Docker Compose для разработки, тестов и production, CI и скрипты резервирования.
- Светлая тема с жёлтыми акцентами и тёмная тема: фон #242834, акцент #b6ff00.
- Переключатель темы в панели и на странице входа; выбор сохраняется в браузере.
