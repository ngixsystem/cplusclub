- Миграция клубов, членства, оборудования, заявок, истории, трудозатрат и outbox.

- Вход без публичной регистрации, команда первого владельца без стандартного пароля.
- Начальные русские страницы обзора, клубов, оборудования, заявок и истории.
- Переходы статусов под блокировкой строки и проверкой версии; контроль результата закрытия.
- Первое время ответа отдельно от времени решения; повторное открытие.
- Расчёт осмотра через два календарных месяца с ограничением днём конца месяца.

## Блокировка среды

Docker Desktop 4.93.0 установлен. CLI Docker 29.8.1 / Compose 5.5.1 доступны по абсолютному пути.
WSL отсутствует; движок Docker недоступен. Установка WSL требует административного действия.
Не запускать PHP/Composer/npm на хосте в обход требования Docker.
Lock-файлы ещё не созданы: их должен сформировать реальный решатель зависимостей внутри контейнеров.
