C+CLUB — исходники лендинга

index.html — разметка и тексты страницы.
style.css — оформление и адаптивная верстка.
app.js — калькулятор тарифов и диалоговые окна.
logo.png — логотип.
services.pdf — описание услуг.

Быстрый просмотр: распакуйте архив и откройте index.html в браузере.
Для запуска через локальный сервер, если установлен Python:
  python -m http.server 8000
Откройте http://localhost:8000

Для размещения на обычном статическом хостинге загрузите эти пять файлов в одну папку.
Сборка и установка npm-пакетов не требуются.
Кнопка «Войти» показывает сообщение о будущем кабинете; авторизация не реализована.
Цены в калькуляторе предварительные; параметры находятся в app.js.

Файлы сайта сохранены без изменений из исходного проекта.
